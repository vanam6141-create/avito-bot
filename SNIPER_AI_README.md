# Avito Sniper AI

Основной запуск проекта переключён на Sniper AI. Старый бот с заданиями больше не запускается; предыдущая версия bot.py сохранена в истории GitHub и может быть восстановлена.

## Переменные окружения
- TELEGRAM_BOT_TOKEN — токен существующего Telegram-бота (прежнее имя переменной можно оставить в Render).
- SNIPER_BOT_TOKEN — необязательное переопределение токена.
- SNIPER_DATABASE_PATH — необязательно, по умолчанию data/sniper.sqlite3.
- SNIPER_MIN_SCORE — необязательно, от 0 до 100, по умолчанию 70.

Не публикуй токен в GitHub и не присылай его в чат.

## Запуск на Mac
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
export TELEGRAM_BOT_TOKEN='ТВОЙ_СУЩЕСТВУЮЩИЙ_ТОКЕН'
python bot.py
```

Для Render Web Service точка входа остаётся python bot.py; endpoint проверки доступности: /health.

## Команды Telegram
- /start — меню и справка
- /addsearch запрос | регион | макс_цена — добавить фильтр
- /searches — показать фильтры
- /pause, /resume — приостановить или включить фильтры
- /status — состояние

## Текущая готовность
Работают основа Telegram-бота, сохранение фильтров в SQLite и эвристическая оценка карточки объявления. Источник объявлений Avito пока не подключён: реальные объявления и уведомления о находках не поступают. Полный мониторинг всех объявлений обещать нельзя. До подключения источника нужно подтвердить разрешённый способ доступа. Не обходить CAPTCHA, авторизацию, лимиты запросов или технические защиты Avito.

Бот не покупает товары и не связывается с продавцами без отдельного подтверждения пользователя. Gmail и платные API не используются.
