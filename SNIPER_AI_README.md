# Avito Sniper AI — отдельный модуль

Этот модуль не меняет существующий `bot.py` и запускается как отдельный Telegram-бот. Текущий этап — проверяемая основа: конфигурация, Telegram-команды, SQLite, фильтры и прозрачная эвристика оценки. **Получение объявлений Avito ещё не подключено**, поэтому бот не заявляет о найденных сделках и не отправляет фиктивные уведомления.

## Требования

- Python 3.12+
- Telegram bot token отдельного бота (не токен старого бота)
- Бесплатные зависимости из `requirements-sniper.txt`

## Установка на Mac

```bash
cd avito-bot
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements-sniper.txt
```

Создай локальный файл `.env` (не добавляй его в Git):

```bash
export SNIPER_BOT_TOKEN='ВСТАВЬ_ТОКЕН_ОТДЕЛЬНОГО_БОТА'
export SNIPER_ADMIN_IDS='ТВОЙ_TELEGRAM_ID'
export SNIPER_DATABASE_PATH='data/sniper.sqlite3'
export SNIPER_MIN_SCORE='70'
```

Запуск:

```bash
python -m sniper_ai.bot
```

Команды в Telegram:

- `/start` — справка и регистрация
- `/addsearch запрос | регион | макс_цена` — создать фильтр
- `/searches` — показать фильтры
- `/pause` и `/resume` — выключить/включить фильтры
- `/status` — состояние

## Проверки

```bash
python -m unittest discover -s tests -v
```

## Безопасность и ограничения

- Не хранить токены в GitHub, исходниках или сообщениях.
- Не подключать Gmail и платные API.
- Не обходить CAPTCHA, вход в аккаунт, ограничения частоты запросов или технические защиты Avito.
- Перед реализацией источника данных нужно подтвердить разрешённый способ доступа (например, официальный API/партнёрский доступ или другой явно разрешённый источник). Открытые страницы не гарантируют полный охват всех объявлений.
- Любая покупка остаётся исключительно за пользователем; модуль не оформляет заказы и не пишет продавцам.

## Архитектура

- `sniper_ai/config.py` — проверяемая конфигурация из переменных окружения.
- `sniper_ai/db.py` — SQLite, внешние ключи, индексы и транзакции.
- `sniper_ai/scoring.py` — прозрачная эвристика оценки, не выдающая себя за ML/AI-экспертизу.
- `sniper_ai/bot.py` — отдельный Telegram polling-процесс.
- `tests/` — автоматические тесты scoring.

Следующий этап после тестирования — подключение законного источника объявлений, затем дедупликация поступающих лотов, уведомления и сравнение с рыночными аналогами.
